JIR Compiler & Register File

The JANUS Intermediate Representation (JIR) compiler is responsible for decomposing 64-bit integer workloads into per-modulus RNS residues and scheduling optical waveguide routing configurations before each computation window opens.

The Register File is a reconfigurable SRAM array. During the optical phase it operates as k independent 8-bit registers — one per modulus lane. During CRT reconstruction it aliases those k registers into a single k×8-bit wide register, mirroring the ARM SVE scalable vector aliasing model.

JIR Compilation Steps
  • Decompose — 64-bit integer → k residues (CRT forward transform)
  • Schedule — assign each residue to a modulus lane
  • Route — program Beneš crossbar with PCM switching configuration
  • Execute — trigger optical computation window
  • Collect — read one-hot detector outputs into register file
