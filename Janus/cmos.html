CMOS Backend Architecture

The CMOS backend is a bounded 33 GHz FSM — not a general-purpose processor. It contains exactly five hardware subsystems dedicated to receiving optical results and reconstructing the 64-bit integer output via CRT arithmetic.

Each subsystem maps to a well-known industry analog, validating the design space against deployed silicon.
