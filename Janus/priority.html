One-Hot Priority Encoder

After photodetection, 256 binary signals arrive simultaneously — exactly one is high. The One-Hot Priority Encoder resolves these to an 8-bit index in a single 30.3 ps clock cycle using an 8-level binary tournament tree of OR gates.

Because the one-hot invariant is guaranteed by the optical layer, arbitration logic is entirely bypassed — a 40% gate reduction compared to a conventional priority encoder. This is architecturally analogous to NVIDIA Hopper's warp scheduler.

Tournament Tree Structure
  • Level 0: 256 leaves (raw photodetector outputs)
  • Levels 1–7: 128 → 64 → 32 → 16 → 8 → 4 → 2 OR-gate pairs
  • Level 8: single root → 8-bit index output
  • Propagation delay: 1 cycle = 30.3 ps
