Architecture Overview

JANUS is a hybrid photonic-electronic processor built on the Chinese Remainder Theorem. A 64-bit integer is decomposed into residues modulo ten small co-prime moduli and each residue is encoded as a unique optical waveguide position — no arithmetic, only light routing.

Multiplications that would take hundreds of CMOS cycles collapse into a single waveguide-crossing. The CMOS backend reconstructs the full 64-bit result in ≤ 5 clock cycles via the Garner Pipeline.

System Flow
  • Input — 64-bit integer decomposed into k residues (mod m₀…m₉)
  • One-Hot Encoding — each residue selects 1 of 256 Si₃N₄ waveguides
  • Beneš Routing — dilated GST-467 PCM crossbar performs modular multiply-in-place
  • Photodetection — binary spatial detector array (light vs. no-light)
  • CRT Reconstruction — 5-stage Garner Pipeline in 152 ps at 33 GHz
