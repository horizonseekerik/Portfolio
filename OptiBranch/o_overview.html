OptiBranch — Architecture Overview

OptiBranch extends JANUS's silicon photonics platform with Gallium Phosphide (GaP) parametric amplification and thin-film lithium niobate (TFLN) integrated optics. The system achieves quantum-noise-limited operation by leveraging three-wave mixing (χ⁽²⁾) to implement amplitude and phase control with zero added electrical noise.

The photonic signal flow: 1550 nm seed → GaP PSA squeezer → TFLN phase modulation → wavelength-division multiplexed lanes → integrated photodetectors → one-hot encoding → digital RNS backend.

Signal Chain
  • Stage 0: Seed + pump generation (1550 nm + 775 nm)
  • Stage 1: GaP PSA (Parametric Signal Amplification)
  • Stage 2: TFLN phase modulators (10-phase encoding)
  • Stage 3: Three-lane wavelength routing
  • Stage 4: Integrated p-i-n photodetectors
  • Stage 5: One-hot optical RNS decoder
