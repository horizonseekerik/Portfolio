NLMZI Binary Amplitude Gating

The Nonlinear Mach-Zehnder Interferometer (NLMZI) is a chip-integrated optical switch that uses χ⁽³⁾ self-phase modulation (SPM) for power-dependent routing. Light intensity builds up in one arm, creating a nonlinear phase shift that routes the signal to the output port—a deterministic, all-optical amplitude gate.

Binary amplitude control (0 → 1 logical state) is implemented by toggling the NLMZI switching threshold: above threshold, photons flip to output port B; below, they remain on port A. No electrical switching, no absorption losses. Operating bandwidth: 20 GHz.
