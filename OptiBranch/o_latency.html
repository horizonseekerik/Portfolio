Latency Analysis & Targets

OptiBranch extends JANUS's digital latency (200 ps) with optical processing stages. The end-to-end latency budget from input RNS digit to reconstructed output spans optical modulation, propagation, photodetection, and analog-to-digital conversion. The key challenge: maintaining < 1 ns total latency to keep branch prediction windows open in modern CPU architectures.

Three-lane parallelism (k=3, 5, 7) enables 64-bit integer decomposition in parallel, and with pipelined detection, throughput reaches 5 Gbps per lane (15 Gbps aggregate).

Performance Targets
  • Single-digit latency: 900 ps (3 lanes in parallel = 300 ps per modulus)
  • Throughput: 5 Gbps per lane → 15 Gbps aggregate (3× JANUS)
  • Power efficiency: ~50 mW/lane × 3 = 150 mW total optical + 100 mW CMOS = 250 mW
