Three-Lane Wavelength Architecture

OptiBranch multiplexes three independent modulation lanes using wavelength-division multiplexing (WDM) with dense spacing: 1545 nm, 1550 nm, 1555 nm (5 nm ITU grid). Each lane independently encodes one residue digit using phase-slot encoding. Integrated dichroic couplers route each wavelength to its own dedicated TFLN modulator and photodetector pair, achieving full parallelism with minimal crosstalk.

WDM multiplexing increases throughput by 3× compared to single-lane operation while keeping the same physical footprint and thermal budget. Chromatic dispersion in each lane is pre-compensated using a common all-pass dispersion compensation module.

Advantages of WDM
  • Parallel encoding: 3 RNS digits computed simultaneously, no serialization
  • Crosstalk isolated: Each lane has dedicated photodetector, no intensity cross-coupling
  • Scalable: Easy to extend to 5 or 10 lanes by increasing spectral density
