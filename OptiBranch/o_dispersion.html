Dispersion Management

Broadband phase modulation across 3 WDM lanes (1545–1555 nm) introduces chromatic dispersion: different wavelengths accumulate different phase delays over propagation, corrupting phase-encoded information. OptiBranch compensates this using a common all-pass linear dispersion module inserted after the PSA stage and before wavelength demultiplexing.

The module uses a cascaded Mach-Zehnder structure with wavelength-dependent path length imbalance to create inverse dispersion: D_comp = −D_fiber. Full compensation is achieved with < 0.2 dB insertion loss across the C-band, enabling phase coherence over > 10 km single-mode fiber links.
